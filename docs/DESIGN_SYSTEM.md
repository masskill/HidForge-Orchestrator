# Дизайн-система HidForge UI

Єдине джерело правди для вигляду всіх сторінок. Принцип — **два спокійні кольори + один акцент**: фон (`bg`) і поверхні (`surface`) створюють структуру, яскравий акцент показує лише головну дію (орієнтовно до 10% видимої сторінки). Вигляд — це **10 стилів × темна / світла тема + режим «Як у системі»** (специфікація HidForge Themes v1.0); типово — **Obsidian Orange**, режим «Як у системі». Чужих ассетів, іконок чи текстів не використано: логотип та іконки намальовано тут.

Стек: **vanilla JS (ES-модулі) + CSS-змінні**, без збірки — так само, як решта проєкту. React/Tailwind свідомо не додано.

## Файли
| Файл | Що всередині |
|---|---|
| `web/styles/tokens.css` | Каталог 20 палітр (`[data-hf-style][data-hf-mode]`), статуси для кожного режиму, похідні ролі для компонентів, радіуси, відступи, типографіка |
| `web/styles/ui.css` | База, AppShell, усі компоненти, адаптивність |
| `web/ui.js` | Компоненти як функції, що повертають DOM-вузли |
| `web/index.html` | Каркас AppShell |
| `web/app.js` | Роутер (`#/projects`, `#/overview`, `#/plan`, `#/tasks[/id]`, `#/planner`, `#/chat`, `#/agents`, `#/activity`, `#/costs`, `#/models`, `#/reports`, `#/system`, `#/settings`) і сторінки, зібрані з компонентів |
| `web/theme.js` | Менеджер вигляду: список стилів, збереження вибору, `system`, синхронізація вкладок; виконується в `<head>` до першого рендеру (без «спалаху») |

## Вигляд: стилі й режими
- На `<html>` стоять `data-hf-style` (стиль) і `data-hf-mode` — **ефективний** режим `dark`/`light`. Вибір користувача (`system`/`dark`/`light`) зберігається окремо.
- Вибір живе в `localStorage` цього браузера: `hidforge.ui.style`, `hidforge.ui.mode`. Старий ключ `hf-theme` (темна/світла/системна) переноситься автоматично: режим зберігається, стиль стає типовим.
- `system` стежить за темою Windows під час роботи; зміна в одній вкладці підхоплюється іншими (подія `storage`).
- Застосунок змінює вигляд через `window.HFTheme`: `get()`, `set({ styleId, mode })`, `reset()`; після кожної зміни — подія `hf-appearance`.
- Сторінка: **Налаштування → Зовнішній вигляд** (`#/settings`, блок `#appearance`): режим, живий перегляд вибраного стилю в обох режимах, 10 карток стилів, «Скинути до типового».

Стилі: `obsidian-orange`, `nordic-blue`, `royal-violet`, `slate-lime`, `arctic-teal`, `champagne-gold`, `berry-noir`, `evergreen`, `deep-ocean`, `crimson-steel`.

### Палітра (8 значень на кожен набір)
| Токен палітри | Призначення |
|---|---|
| `--hf-bg` / `--hf-surface` | два спокійні шари: фон застосунку / картки, таблиці, панелі |
| `--hf-text` / `--hf-text-secondary` | основний текст / дрібний другорядний текст |
| `--hf-muted` | вихідний приглушений відтінок (лише лінії й декор — у світлих темах блідий для тексту) |
| `--hf-accent` / `--hf-on-accent` | єдиний акцент / текст на акцентній заливці |
| `--hf-accent-fill` | заливка головної кнопки; дорівнює `accent`, крім Arctic Teal світлої (`#008477` замість `#008678`, щоб білий текст мав ≥ 4.5:1) |

### Ролі для компонентів (похідні, однакові для всіх стилів)
Компоненти використовують лише ці токени й ніколи — назву стилю. Похідні — це суміші кольорів самої палітри (`color-mix`), четвертого відтінку немає.
| Токен | Звідки | Призначення |
|---|---|---|
| `--bg-app` / `--bg-panel` | `bg` / `surface` | фон / картки |
| `--bg-sidebar` / `--bg-panel-alt` / `--bg-input` | між `bg` і `surface`; `surface` + 4% тексту; між `bg` і `surface` | бічна панель / вкладені поверхні / поля |
| `--bg-active` / `--bg-hover` | `surface` + 6% тексту / 6% тексту | вибрана зона (нейтральна) / наведення |
| `--border` / `--border-soft` / `--border-strong` | 13% / 9% / 24% тексту | межі |
| `--text` / `--text-2` / `--text-muted` | `text`; `text-secondary` + 22% / 8% тексту | текст за ієрархією |
| `--accent` / `--accent-fill` / `--accent-hover` / `--accent-pressed` / `--accent-soft` | `accent`, `accent-fill`, заливка + 14% / 26% тексту, 14% акценту на `surface` | головна дія, маркер вибраного, фокус |
| `--accent-text` | `accent` + 20% тексту | акцент як дрібний текст (бейдж, наведення на посилання) — ≥ 4.5:1 |
| `--on-accent` | `on-accent` | текст на головній кнопці |
| `--success` `--warning` `--danger` `--info` (+ `*-soft`) | окремо для темного й світлого режиму | статуси; ніколи не замінюють акцент |
| `--focus` | кільце 2 px кольору акценту з відступом | видимий фокус клавіатури |
| `--brand-orange` / `--brand-mint` | сталі | лише логотип: айдентика не перефарбовується під акцент |
| `--r-sm/md/lg/xl`, `--s-1…--s-6`, `--font` / `--mono` | — | радіуси 8/12/16/20 px, відступи 4–32 px, системні шрифти |

### Ролі кольорів
- **Акцент:** одна залита головна кнопка на контекст, тонкий маркер активного пункту меню (лінія ліворуч на нейтральному тлі), лінія під вибраною вкладкою, маркер вибраного рядка, рамка вибраної картки стилю, головний прогрес, фокус.
- **Не акцент:** іконки, заголовки, лічильники меню, порожні стани, прогрес етапів (нейтральний), другорядні кнопки.
- **Статуси:** зелений — злито, прийнято, готово; синій — інформація; жовтий — увага; червоний — помилка, видалення. Статус ніколи не передається лише кольором: поруч завжди текст.

### Як додати нову палітру
1. У `tokens.css` додати два блоки `[data-hf-style="id"][data-hf-mode="dark|light"]` з усіма 8 значеннями `--hf-*`.
2. У `web/theme.js` додати `{ id, name, text }` у `STYLES`.
3. `node --test test/themes.test.ts` — перевіряє, що кожен стиль має обидва режими й усі значення, і базовий контраст (текст ≥ 7:1, другорядний текст і текст кнопки ≥ 4.5:1).

### Як перевірити всі 20 комбінацій
Автоматично: `test/themes.test.ts` (каталог, контраст, логіка `theme.js`). У браузері: на сторінці налаштувань у консолі перебрати `HFTheme.STYLES × ['dark','light']` через `HFTheme.set(...)` і порахувати контраст обчислених кольорів (`getComputedStyle`) для пар текст/фон, кнопка, бейджі; вручну — пройти Огляд, Задачі (форма), Налаштування на 1366, 1920 і 390 px.

Правило: у компонентах і сторінках — лише змінні з `tokens.css`, жодних «сирих» кольорів.

## Адаптивність
- **≥1800px (широкий десктоп):** ширша бічна панель.
- **≤1280px (ноутбук):** деталі задачі переходять під таблицю.
- **≤1024px (планшет):** бічна панель стає висувною (кнопка «Меню», затемнення фону).
- **≤720px (мобільний):** сітки в одну колонку, таблиці — картками, кнопки ≥42px.
- Жодної горизонтальної прокрутки сторінки: треки grid мають `minmax(0, 1fr)`.

## Доступність
- Видимий фокус (`--focus`).
- Семантичні `nav`, `main`, `dialog`, `role=tablist/tab/tabpanel`, `aria-current`, `aria-selected`.
- Рядки таблиці доступні з клавіатури (Tab + Enter).
- `prefers-reduced-motion` вимикає анімації.
- Увесь недовірений текст виводиться через `textContent`.

## Як додати нову сторінку
1. Додайте запис у `PAGES` (`web/app.js`) з `id`, підписом та іконкою.
2. Напишіть функцію `xxxPage()`: `mount(PageHeader(...), PanelCard(...), ...)`, лише з компонентів `ui.js`.
3. Новий візуальний елемент спершу робіть компонентом у `ui.js` / `ui.css` на токенах, а не одноразовим стилем сторінки.
